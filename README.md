# Telegram UI Clone

یک نمونه صفحه‌ی رابط کاربری شبیه تلگرام که با Tailwind CSS ساخته شده است.

## ویژگی‌ها
- چت‌بات شبیه تلگرام
- سایدبار چت‌ها
- پیام‌های راست و چپ
- بخش اطلاعات تماس در دسکتاپ
- طراحی ریسپانسیو
- بدون نیاز به نصب پیچیده

## اجرا
در پروژه فقط کافی است فایل `index.html` را در مرورگر باز کنید.

اگر بخواهید، می‌توانم نسخه‌ی دوم را هم با:
- Vite + Tailwind
- ساختار React
- حالت تاریک و روشن
- نسخه‌ی کامل‌تر mobile first

برای شما بسازم.
